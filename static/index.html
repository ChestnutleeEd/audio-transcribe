使用教程

            
从准备环境到导出结果的基本流程。

          

          
        

        
    
          
  1. 检查环境。从左侧进入“环境检查”和“模型检测”；缺少依赖时点“查看修复建议”查看处理步骤。
    2. 
          
  2. 选择来源。上传本地音频/视频，或填写 YouTube、Bilibili 链接；同时填写时优先处理上传文件。
    3. 
          
  3. 选择转录模型。Whisper 用本地 Whisper 模型；MLX Whisper 需要 MLX 格式模型；本地音频大模型只显示已检测到的音频模型。
    4. 
          
  4. 配置输出。选择语言、时间轴、导出格式和导出内容；SRT 需要开启时间轴。
    5. 
          
  5. 整理文本。开启“使用本地大模型整理转录结果”，选择 Text 模型，并勾选一个或多个文本整理配置；可以追加指令或编辑 prompt。
    6. 
          
  6. 查看结果。任务完成后进入“文件任务”复制、下载、对比原文和整理后文本；最近历史可单独查看。
    7. 
          
  7. 强制刷新。如果页面资源没有更新，按 Command + Shift + R 强制刷新浏览器缓存。
