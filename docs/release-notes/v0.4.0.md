# Audio Transcribe v0.4.0

`v0.4.0` 将当前所有有效分支改动汇总到 `main`，更新完整产品说明与最新版界面截图，并首次提供真正包含运行环境的 Windows / macOS 发布包。

## 新功能与体验

- 新增“系统状态”总览：集中展示当前转录路径、模型池、平台、导出设置、文本整理、关键依赖和运行建议。
- 改进本地模型检测与模型池视图，并行探测 Ollama、MLX、Hugging Face 缓存、llama.cpp 和自定义模型目录。
- 新增模型注册缓存与强制刷新机制，减少重复磁盘扫描和页面等待。
- 完善自动保存目录、文件夹选择器、任务状态和长内容布局。
- 优化深浅色界面、工作台配置摘要和本地模型详情视图。

## 稳定性

- 媒体命令支持超时、取消与子进程清理，减少下载或 FFmpeg 任务卡住的情况。
- 限制导出文件名长度，提升 Windows / macOS 文件系统兼容性。
- 改进 MLX VLM Audio、Ollama 文本整理和 Qwen Audio 预处理。
- FastAPI 启动流程迁移到 lifespan，并在服务启动时创建运行目录。

## 开箱即用发行包

- `AudioTranscribeSetup.exe`：Windows x64 安装器。
- `AudioTranscribe-v0.4.0-windows-x64.zip`：Windows x64 便携版。
- `AudioTranscribe.dmg`：Apple Silicon macOS 安装器。
- `AudioTranscribe-v0.4.0-macos.zip`：Apple Silicon macOS 便携版。
- 四个产物均由对应系统的 GitHub 构建机生成，内置可再发行 Python 3.12、Python 依赖、FFmpeg 和 FFprobe。
- 启动器会再次检查运行环境；依赖缺失时默认通过清华 PyPI 镜像补齐。

> Whisper、MLX Audio、MLX VLM 和 Ollama 模型体积较大，仍不会打进安装包。应用只使用用户明确下载或绑定的本地模型，不会静默调用云服务。

## 验证

- Python 测试：42 passed，4 subtests passed。
- 浏览器验证：首页、转录工作台和系统状态页均使用当前 `v0.4.0` 代码重新截图。
- Release 工作流在 Windows 与 Apple Silicon macOS 原生构建机上验证内置 Python 依赖、测试套件和产物体积后才允许发布。
