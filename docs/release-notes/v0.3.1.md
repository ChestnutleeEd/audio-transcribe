# Audio Transcribe v0.3.1

本版本聚焦工作台布局修复和 macOS / Windows 开箱即用说明，适合所有使用 `v0.3.0` 的用户升级。

## 修复

- 修复转录工作台左侧“新建任务”面板在展开自动存储设置后内容溢出白色背景的问题。
- 修复滚动到工作台底部时右侧“转录参数”区域出现大块外层背景空白的问题。
- 修复“新建任务”标题和“开始转写”按钮随滚动遮挡内容的问题，二者现在会跟随面板内容正常滚动。

## 文档

- README 新增 `v0.3.1` 最新推荐版本说明。
- README 补充 Windows 安装器、Windows ZIP、macOS 安装器、macOS ZIP 和源码启动的开箱即用路径。
- README 明确启动脚本默认使用清华 PyPI 镜像，并补充 Homebrew 国内镜像示例。
- README 构建命令更新为 `v0.3.1`。

## 发行说明

- Windows 普通用户优先使用 `AudioTranscribeSetup.exe`。
- macOS 普通用户优先使用 `AudioTranscribe.dmg` 或 `AudioTranscribeAppBundle.zip`。
- ZIP 便携版继续保留，适合测试、临时使用和开发调试。
- Whisper、MLX Whisper、Qwen2-Audio 和 Ollama 模型仍不会内置在发行包中，首次使用请在页面内下载或手动配置本地模型。

## 验证

- 已用浏览器在宽屏工作台下验证：自动存储设置展开后，左侧提交按钮仍在白色面板内。
- 已用浏览器验证：滚动到最底部时，左右面板底部对齐，右侧不再露出大块外层背景。
