# Audio-Transcribe v1.0.0 发行路线图

目标：把 Audio-Transcribe 从本地脚本项目升级为普通用户可以安装、启动、卸载和升级的桌面软件。

## 版本策略

- `v0.2.x`：开发版。保留 ZIP，修正发行说明，建立双发行目录和安装器构建骨架。
- `v0.9.x`：安装器测试版。重点验证安装器、快捷方式、卸载、默认配置、依赖检测和升级路径。
- `v1.0.0`：正式桌面应用。安装器成为推荐入口，ZIP 作为便携和开发入口保留。

## ZIP 便携版

ZIP 版必须继续保留，适合不想安装软件、临时试用、开发调试和手动部署的用户。

目标：

- Windows ZIP：保留 `start-audio-transcribe.bat` 和 `stop-audio-transcribe.bat`。
- macOS ZIP：保留 `start-audio-transcribe.command` 和 `stop-audio-transcribe.command`。
- 启动器统一检查 Python、FFmpeg、Python 依赖和本地服务状态。
- 依赖缺失时显示中文安装步骤，不直接崩溃。
- 明确提示 ZIP 是“半开箱即用”，不承诺内置所有运行环境。

## Windows 安装器

目标产物：

```text
AudioTranscribeSetup.exe
```

推荐技术路线：

1. PyInstaller 打包 Python 启动层或准备 Python embedded runtime。
2. Inno Setup 生成安装器。
3. 安装器创建桌面快捷方式和开始菜单入口。
4. 安装器写入默认配置文件。
5. 安装器提供卸载入口。

v1.0.0 验收目标：

- 普通用户双击安装器即可安装。
- 安装后可以从桌面快捷方式启动。
- 启动失败时显示中文原因和处理步骤。
- 卸载入口正常工作。
- 不要求用户理解 Python 虚拟环境。

## macOS 安装器

目标产物：

```text
AudioTranscribe.dmg
```

推荐技术路线：

1. 构建 `Audio-Transcribe.app` 应用包。
2. 使用 `hdiutil` 生成 dmg。
3. 提供拖拽到 Applications 的安装体验。
4. Apple Silicon 优先支持 MLX Whisper。
5. 如果无法随包携带某些系统依赖，首次运行必须显示中文引导。

v1.0.0 验收目标：

- 普通用户打开 dmg 后可以安装到 Applications。
- 首次启动有清晰中文引导。
- Apple Silicon 用户可以清楚看到 MLX Whisper 的配置路径。
- 缺少 FFmpeg 或模型时不崩溃。

## 构建目录

统一输出目录：

```text
dist/
  zip/
    windows/
    macos/
  installer/
    windows/
    macos/
```

构建脚本必须保留以下目标：

- `build_zip_windows`
- `build_zip_macos`
- `build_installer_windows`
- `build_installer_macos`

## 不做的事

- 不把 Whisper、MLX Whisper 或 Ollama 模型默认塞进发行包。
- 不把 ZIP 描述成完全开箱即用。
- 不在缺少安装器工具时生成伪安装包。
- 不批量删除旧构建产物。
