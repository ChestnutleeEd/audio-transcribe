# Audio Transcribe v0.3.0

本版本同时推进两条主线：稳定 ZIP + Installer 双发行体系，并新增本地 Qwen2-Audio MLX 多模态音频理解 pipeline。

## 新增能力

- 新增 Qwen2-Audio 引擎：`mlx-community/Qwen2-Audio-7B-Instruct-4bit`。
- 新增音频预处理 pipeline：16kHz 单声道、15 到 30 秒 chunk、0 到 2 秒 overlap。
- 新增 chunk 级 streaming：任务运行中会逐步写入 `partial_results`、`rawText`、`segments` 和 engine metadata。
- 新增严格 Qwen JSON 输出：

```json
{
  "audio_file": "...",
  "duration": 123,
  "model": "Qwen2-Audio-7B-Instruct-4bit",
  "backend": "mlx-audio",
  "segments": [
    {
      "id": 1,
      "start": 0,
      "end": 15,
      "text": "..."
    }
  ],
  "full_text": "..."
}
```

## 本地依赖

- Qwen2-Audio 仅面向 macOS Apple Silicon。
- 需要自行安装 `mlx-audio`：

```bash
pip install -r requirements-qwen-audio.txt
```

- 本项目不会自动下载 Qwen2-Audio 模型，也不会使用 OpenAI API 或云端推理。建议先在应用外下载模型：

```bash
huggingface-cli download --local-dir models/Qwen2-Audio-7B-Instruct-4bit mlx-community/Qwen2-Audio-7B-Instruct-4bit
```

## 发行构建

- Windows ZIP 与 macOS ZIP 继续输出到 `dist/zip`。
- Windows Installer 输出到 `dist/installer/windows`，只有检测到真实 Inno Setup `ISCC.exe` 时才会生成 `AudioTranscribeSetup.exe`。
- macOS Installer 输出到 `dist/installer/macos`，优先使用 `create-dmg` 生成 dmg；未检测到 `create-dmg` 时 fallback 为真实 `.app` bundle ZIP。
- Installer 构建失败不会生成假文件，会中文提示原因并 fallback ZIP。

## 已知限制

- macOS `.app` 当前仍会打开 Terminal 启动本地服务。
- 未签名 / 未公证 dmg 或 app bundle 仍可能触发 Gatekeeper 提示。
- Qwen2-Audio 的真实时间戳来自 chunk 边界，不等同于 Whisper 的词级或句级时间戳。
