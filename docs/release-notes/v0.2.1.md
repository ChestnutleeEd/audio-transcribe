# Audio-Transcribe v0.2.1

本版本是发行体系修正版，重点不是新增转写能力，而是把项目从“脚本启动项目”升级为“ZIP 便携版 + 安装器版本”的双发行体系。

## 重要修正

- 修正 ZIP 便携版说明：ZIP 不再被描述为完全开箱即用，而是明确为“半开箱即用”。
- 新增安装器版本规划：Windows 安装器目标产物为 `AudioTranscribeSetup.exe`，macOS 安装器目标产物为 `AudioTranscribe.dmg`。
- 新增统一构建目录：

```text
dist/
  zip/
    windows/
    macos/
  installer/
    windows/
    macos/
```

- 升级 `scripts/build-release.ps1`，新增四个构建目标：
  - `build_zip_windows`
  - `build_zip_macos`
  - `build_installer_windows`
  - `build_installer_macos`
- 新增 Windows Inno Setup 配置，作为 Windows 安装器基础。
- 新增 macOS `.app` 和 `.dmg` 构建骨架，作为 macOS 安装器基础。
- 新增运行时检查脚本，统一检查 Python、FFmpeg 和 Python 依赖。
- README 重构为产品说明书级别，明确推荐安装器、ZIP 差异、依赖、首次启动、关闭方式和常见问题。

## 当前限制

- Windows 安装器需要在 Windows 构建机安装 Inno Setup 后生成。
- macOS dmg 需要在 macOS 构建机使用 `hdiutil` 生成。
- 如果构建机没有准备 Python runtime 或 FFmpeg，安装器构建脚本会用中文报错，不会生成误导性的安装包。
- Whisper、MLX Whisper 和 Ollama 模型不会内置在发行包中，用户首次使用时仍需下载或手动配置。

## 推荐下载

普通用户优先选择安装器版本：

- Windows：`AudioTranscribeSetup.exe`
- macOS：`AudioTranscribe.dmg`

测试、开发或临时使用再选择 ZIP 便携版：

- Windows：`AudioTranscribe-v0.2.1-windows-x64.zip`
- macOS：`AudioTranscribe-v0.2.1-macos.zip`
