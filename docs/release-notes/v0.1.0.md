# Audio Transcribe v0.1.0

首个便携发行版，面向本地音视频转写和视频链接转写。

## 重要说明

- 发行版不内置 Whisper 模型。首次运行后，请在页面右侧下载模型，或参考 README 的“本地模型”章节手动放入 `models/`。
- Windows 包内置 Python 虚拟环境和 FFmpeg / FFprobe，解压后可直接运行 `start-audio-transcribe.bat`。
- macOS 包不内置 Python 虚拟环境，需要先安装 FFmpeg；首次运行会自动创建 `.venv` 并安装 Python 依赖。

## 下载

- `AudioTranscribe-v0.1.0-windows-x64.zip`：Windows x64 便携包。
- `AudioTranscribe-v0.1.0-macos.zip`：macOS 便携包。

## 快速开始

### Windows

1. 下载并解压 `AudioTranscribe-v0.1.0-windows-x64.zip`。
2. 双击 `start-audio-transcribe.bat`。
3. 浏览器打开后，在页面右侧下载或选择本地 Whisper 模型。

### macOS

1. 下载并解压 `AudioTranscribe-v0.1.0-macos.zip`。
2. 安装 FFmpeg：

```bash
brew install ffmpeg
```

3. 给脚本授权并启动：

```bash
chmod +x scripts/setup-macos.sh start-audio-transcribe.command
./start-audio-transcribe.command
```

4. 浏览器打开后，在页面右侧下载或选择本地 Whisper 模型。
