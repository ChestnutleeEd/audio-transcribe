# Audio Transcribe v0.2.0

本次版本重点增强本地模型工作流、文本整理能力、启动/停止体验和错误诊断。适合需要在本机完成转写、整理、导出和复查的用户升级。

## 重要说明

- 发行版仍不内置 Whisper、MLX Whisper 或 Ollama 模型。首次运行后，请在页面中下载 faster-whisper 模型，或按 README 的“本地模型”章节手动放置模型。
- Windows ZIP 包会包含项目文件和启动/停止脚本。它不是完整安装器，也不保证内置 Python runtime、FFmpeg 或 FFprobe。若包内没有运行环境，请按 README 的依赖说明执行首次安装。
- macOS 包不内置 Python 虚拟环境。首次运行 `start-audio-transcribe.command` 时会自动创建 `.venv` 并安装 Python 依赖；FFmpeg 需要通过 Homebrew 等方式自行安装。
- MLX Whisper 和 Ollama 都是可选能力，应用只负责检测、配置和调用，不会自动安装 MLX、Ollama 或下载对应模型。
- 从 `v0.2.1` 开始，项目将进入 ZIP 便携版和 Installer 安装版并行的发行体系。

## 下载

- `AudioTranscribe-v0.2.0-windows-x64.zip`：Windows x64 便携包。
- `AudioTranscribe-v0.2.0-macos.zip`：macOS 便携包。

## 新增与改进

- 新增 MLX Whisper 工作流：Apple Silicon Mac 可在页面中选择 MLX Whisper，并填写本地模型目录或已缓存的 Hugging Face repo id。
- 新增本地大模型音频转录入口：可显式选择 Ollama 本地多模态模型进行实验性音频直转。
- 新增 Ollama 文本整理后处理：支持标点修复、保守清理、日语自然断句、中文会议纪要和双语翻译等配置。
- 新增提示词预览和追加自定义指令：自定义指令只追加在基础安全模板之后，保留原始转录和结构化校验逻辑。
- 新增原始文本 / 整理后文本同屏展示，支持复制、重新整理和段落级对比。
- 改进长文本整理：按 segment 分批调用 Ollama，降低漏段、合并段落和输出截断风险；失败批次会保留原始文本。
- 改进模型检测：页面环境检查覆盖 faster-whisper、Whisper 模型、FFmpeg、Ollama 服务和本地 Ollama 模型。
- 改进模型下载：显示更细的下载阶段、百分比、已下载大小，并支持取消下载。
- 改进启动和关闭：新增 Windows / macOS 停止脚本，并补充 `docs/START_AND_STOP.md`。
- 改进任务状态：任务卡片展示实时处理耗时、完成总耗时、失败原因、事件时间线和错误诊断建议。
- 改进导出：支持 TXT、Markdown、JSON、SRT 和 Word，导出范围可选择原始文本、整理后文本或两者同时导出。
- 改进链接任务：自动清理 YouTube 时间参数，下载成功后用视频标题作为任务名称，同时保留原视频链接。

## 快速开始

### Windows

1. 下载并解压 `AudioTranscribe-v0.2.0-windows-x64.zip`。
2. 双击 `start-audio-transcribe.bat`。
3. 浏览器打开后，在页面右侧下载或选择本地 Whisper 模型。
4. 需要关闭服务时，回到启动窗口按 `Ctrl + C`，或双击 `stop-audio-transcribe.bat`。

### macOS

1. 下载并解压 `AudioTranscribe-v0.2.0-macos.zip`。
2. 安装 FFmpeg：

```bash
brew install ffmpeg
```

3. 给脚本授权并启动：

```bash
chmod +x scripts/setup-macos.sh start-audio-transcribe.command stop-audio-transcribe.command
./start-audio-transcribe.command
```

4. 浏览器打开后，在页面右侧下载或选择本地 Whisper 模型。
5. 需要关闭服务时，回到启动 Terminal 窗口按 `Control + C`，或双击 `stop-audio-transcribe.command`。
